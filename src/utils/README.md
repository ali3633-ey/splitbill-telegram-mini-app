# Утилита разделения счёта

Чистая TypeScript-функция для корректного разделения счёта между участниками.

## Особенности

✅ **Точное округление** - все суммы округляются до 2 знаков после запятой  
✅ **Сходимость суммы** - гарантируется, что сумма всех долей равна общей сумме  
✅ **Справедливое распределение** - остаток от деления добавляется последнему участнику  
✅ **Чистая функция** - без побочных эффектов, легко тестируется  
✅ **Валидация** - проверка входных данных и результата

## Использование

```typescript
import { splitBill } from './utils/splitBill';

const participants = [
  { id: '1', name: 'Алиса' },
  { id: '2', name: 'Боб' },
  { id: '3', name: 'Чарли' }
];

const result = splitBill(participants, 100, 'equal');
// [
//   { name: 'Алиса', amount: 33.33 },
//   { name: 'Боб', amount: 33.33 },
//   { name: 'Чарли', amount: 33.34 }  // ← последний получает остаток
// ]
```

## API

### `splitBill(participants, totalAmount, mode)`

**Параметры:**
- `participants: Participant[]` - массив участников с `id` и `name`
- `totalAmount: number` - общая сумма для разделения
- `mode: 'equal'` - режим деления (пока только равное деление)

**Возвращает:**
- `ParticipantShare[]` - массив с `name` и точной суммой `amount`

### `validateSplit(shares, totalAmount)`

Проверяет, что сумма всех долей равна общей сумме (с точностью до 1 копейки).

**Параметры:**
- `shares: ParticipantShare[]` - результат функции `splitBill`
- `totalAmount: number` - исходная общая сумма

**Возвращает:**
- `boolean` - `true` если сумма сходится

## Примеры

### Пример 1: Классическое деление
```typescript
splitBill(
  [{ id: '1', name: 'A' }, { id: '2', name: 'B' }],
  100,
  'equal'
);
// [{ name: 'A', amount: 50 }, { name: 'B', amount: 50 }]
```

### Пример 2: Неделимая сумма
```typescript
splitBill(
  [
    { id: '1', name: 'Иван' },
    { id: '2', name: 'Мария' },
    { id: '3', name: 'Петр' }
  ],
  1000,
  'equal'
);
// [
//   { name: 'Иван', amount: 333.33 },
//   { name: 'Мария', amount: 333.33 },
//   { name: 'Петр', amount: 333.34 }  // ← +0.01 к последнему
// ]
```

### Пример 3: Сложная сумма
```typescript
splitBill(
  Array.from({ length: 7 }, (_, i) => ({ 
    id: String(i), 
    name: `Участник ${i + 1}` 
  })),
  1234.56,
  'equal'
);
// [
//   { name: 'Участник 1', amount: 176.36 },
//   { name: 'Участник 2', amount: 176.36 },
//   { name: 'Участник 3', amount: 176.36 },
//   { name: 'Участник 4', amount: 176.36 },
//   { name: 'Участник 5', amount: 176.36 },
//   { name: 'Участник 6', amount: 176.36 },
//   { name: 'Участник 7', amount: 176.40 }  // ← +0.04
// ]
```

## Алгоритм

1. **Базовая доля**: `Math.floor((totalAmount / count) * 100) / 100`
   - Округление вниз до 2 знаков для каждого участника

2. **Остаток**: `totalAmount - (baseAmount × count)`
   - Вычисляем разницу между общей суммой и распределенной

3. **Корректировка**: Добавляем остаток к последнему участнику
   - Гарантирует точное совпадение сумм

4. **Валидация**: Проверяем, что `sum(amounts) === totalAmount`

## Расширение

В будущем можно добавить другие режимы:
- `'weighted'` - разделение с весами (кто сколько съел)
- `'custom'` - произвольные суммы для каждого
- `'percentage'` - разделение в процентах

## Математическая гарантия

Для любых входных данных выполняется:
```typescript
const result = splitBill(participants, totalAmount, 'equal');
const sum = result.reduce((acc, s) => acc + s.amount, 0);
Math.abs(sum - totalAmount) < 0.01; // всегда true
```
