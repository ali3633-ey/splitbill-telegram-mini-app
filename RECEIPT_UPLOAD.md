# Быстрый старт: Загрузка чека

## Как использовать

1. **Создайте счёт** - введите название (например, "Ужин в ресторане")

2. **Загрузите фото чека**:
   - Нажмите на область "📸 Загрузить чек"
   - Выберите фото чека (JPEG, PNG, WebP)
   - Максимальный размер: 10MB

3. **Распознайте текст**:
   - Нажмите "🔍 Распознать чек"
   - Подождите 1-2 секунды
   - Сумма автоматически заполнится

4. **Отредактируйте при необходимости**:
   - Если сумма определена неверно, исправьте текст
   - Сумма обновится автоматически

5. **Добавьте участников** и разделите счёт

## Пример результата OCR

```
Ресторан "Вкусно"
Ул. Пушкина, д.10

Дата: 03.02.2026
Время: 19:30

Салат Цезарь       450.00
Паста Карбонара    680.00
Стейк              1200.00
Десерт             320.00
Кофе x2            300.00

---------------------------
Итого:            2950.00
Сервис (10%):      295.00
---------------------------
К оплате:         3245.00
```

## Текущая версия (Mock)

Сейчас используется **демо-версия** OCR для разработки:
- Всегда возвращает один и тот же текст чека
- Не анализирует реальное изображение
- Служит для тестирования интерфейса

## Для production

Замените `mockOCR` на реальный API:
- Google Cloud Vision API
- Azure Computer Vision  
- AWS Textract
- Tesseract.js

Инструкции см. в [OCR_README.md](./OCR_README.md)
